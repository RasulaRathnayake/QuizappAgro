# 🌾 AgroMaster Quiz

A responsive, interactive quiz application for agriculture students, designed for **School of Agriculture, Kundasale**. Works on **desktops, laptops, tablets, and smartphones**.

---

## 📌 Features

- Select number of questions (2, 4, 6, 8, 10)  
- Choose agriculture topics:  
  - Upcountry Vegetables  
  - Low Country Vegetables  
  - Fruit Crops  
  - Fertilizer & Irrigation  
  - Pest & Technology  
  - Bee Keeping & Advanced  
- Set time per question (10–60 seconds)  
- Interactive quiz with:  
  - Timer & progress bar  
  - Highlight correct/incorrect answers  
  - Submit & next buttons  
- Final score summary  
- Fully **responsive** for all screen sizes  

---

## 🖥️ Requirements

- Modern web browser (Chrome, Safari, Firefox, Edge)  
- No backend/server required  
- Works offline
